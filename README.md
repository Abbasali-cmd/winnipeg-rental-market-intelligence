# Winnipeg Rental Market Dynamics

End-to-end statistical analysis of Winnipeg rental supply, prices, vacancy, and market affordability using CMHC and Statistics Canada data.

## Research Question

How do rental prices, vacancy rates, housing supply, and neighbourhood characteristics vary across Winnipeg, and what factors are associated with rental-market pressure and affordability?

## Data

- Canada Mortgage and Housing Corporation (CMHC) Rental Market Survey
- Statistics Canada 2021 Census data
- Winnipeg Census Tract and neighbourhood-level analysis

## Analysis

The project covers:

- Rental housing supply and bedroom composition
- Average rents by bedroom type
- Vacancy rates
- Median household income
- Rent-to-income affordability indicators
- Correlation analysis
- Multiple linear regression
- Model diagnostics and sensitivity analysis
- Dashboard-ready analytical datasets

## Important Interpretation Note

The rent-to-income measure is an ecological market-level indicator based on average rental prices and median household income. It should not be interpreted as an individual household rent-burden measure.

## Reproducibility

Raw source files are excluded from version control where appropriate. The analysis notebook and project structure are provided to support reproducibility.
